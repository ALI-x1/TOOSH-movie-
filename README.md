# TOOSH MOVIE (توش مووی)

Web application version of **TOOSH MOVIE** (`v2.4`), built with React, TypeScript, Vite, and Tailwind CSS v4.

## Features
- **Persian RTL Cinema Ticket / Neo-Brutalist UI** with 10 themes across 5 color families and animated circular reveal transitions
- **Home, Movies, Series, Categories & Live Search** with polite API queueing, caching, and automatic primary/backup failover
- **Continue Watching**, watch history, likes, saved items, and customizable user profile
- **Movie & Series Details** with grouped subtitle/dubbed quality tickets, trailer playback, season/episode accordion, bulk copy, and batch download
- **In-App HTML5 Video Player** supporting speed controls, seek hover preview, local & URL `.srt`/`.vtt` subtitles, and byte-range MKV EBML subtitle extraction
- **Diagnostics & Settings** with font size controls, lite mode, cache clearing, and live server connectivity tests

## Development
```bash
npm install
npm run dev
```

Runs on `http://localhost:3000`.

## Build & Typecheck
```bash
npm run lint
npm run build
```
